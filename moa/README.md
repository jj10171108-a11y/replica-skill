# 모아 가계부

수입·지출, 신용카드, 투자, 부채, 저축 목표를 한눈에 보는 가계부 웹앱(PWA).
아이폰은 Safari로 열고 **공유 → 홈 화면에 추가**하면 앱처럼 설치됩니다.

- 서버·회원가입 없음. 데이터는 각자의 기기(브라우저 저장소)에만 저장됩니다.
- 설정 → 백업 파일 저장/불러오기로 기기를 옮길 수 있습니다.
- 오프라인에서도 동작합니다 (sw.js). index.html을 바꾸면 sw.js의 VERSION도 올려 주세요.

정적 파일 6개뿐이라 GitHub Pages, Vercel, Netlify 등 아무 정적 호스팅에 올리면 됩니다.
