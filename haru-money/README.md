# 하루 가계부 (Haru Money)

오프라인 개인 가계부 앱 (Expo / React Native). 가입·광고·추적 없이 모든 데이터와 계산이 휴대폰 안에서만 이뤄집니다.

F-Droid의 오픈소스 가계부 앱 Cryo의 **공개된 기능 설명만 참고해 새로 만든** 앱입니다. 원본(AGPL)의 코드·디자인·문구·아이콘은 사용하지 않았습니다.

## 기능

| 기능 | 내용 |
| --- | --- |
| 문장으로 기록 | "점심 12000 체크카드", "어제 택시 15000 현금", "TV 48만 10개월 할부 신용카드", "월급 320만 입금", "통장에서 현금으로 5만 이체" → 금액·카테고리·계좌·날짜·할부를 자동으로 채움. "3만5천", "1.2만", "삼만오천원" 같은 한국어 금액도 인식. 음성은 키보드 마이크로 |
| 월말 예측 | 지난 90일 기록으로 2,000가지 시나리오를 시뮬레이션해 월말 잔액 범위(10~90%)와 적자 확률, 이번 달 예상 지출 |
| 고정 수입·지출 자동 찾기 | 3개월 이상 비슷한 날·금액으로 반복된 급여·월세·구독·공과금을 스스로 찾고, 한 번에 등록 |
| 12개월 전망 | 고정 수입·지출, 평소 지출, 빚 상환 일정으로 앞으로 1년 잔액 그래프 |
| 이상 지출·중복 결제 | 같은 항목·카테고리 평소보다 훨씬 큰 지출, 같은 날 같은 금액 두 번 결제 |
| 재정 건강 점수 | 저축률·비상금·빚 부담·예산 지키기 4가지로 100점 만점 + 팁 |
| 지출 캘린더·요일 패턴·돈의 흐름 | 날짜별 지출 히트맵, 요일별 평균, 수입 → 지출 흐름도, 카테고리별 비율 |
| 신용카드 | 사용 기간 마감일·결제일로 청구서 자동 분류, 할부 회차를 맞는 청구서에, 남은 한도, 통장에서 대금 납부 |
| 빚 | 대출·할부 계약·분할 합의·개인 차용: 남은 금액, 연체 회차, 숨은 연 이자율, 다 갚는 날, 수입 대비 상환 비율, 이자 높은 순 상환 계획과 추가 상환 시 아끼는 이자 |
| 계획 | 카테고리별 월 예산(속도 표시), 저축 목표(매달 모을 금액 제안), 고정 지출 알림 |
| 투자 | 투자 계좌로 이체한 시점을 반영한 실제 연 수익률(XIRR) |
| 은행 내역 가져오기 | CSV(쉼표·세미콜론·탭, 출금/입금 칸 또는 금액 칸), OFX. 가져오기 전 확인 화면에서 카테고리 제안, 이미 있는 거래는 체크 해제, 카드 대금 출금 자동 인식 |
| 보안·백업 | 지문·얼굴·화면 잠금, JSON 백업(선택: 비밀번호로 AES-256-GCM 암호화, scrypt 키), CSV 내보내기, 백업 알림 |
| 기타 | 처음 실행 시 애니메이션 사용법(동작 줄이기 설정 존중), 라이트/다크, 원·달러·유로·엔, 예시 데이터 |

### 원본과 다른 점 / 아직 없는 것
- 언어는 한국어만 지원합니다 (원본은 10개 언어).
- 내역 가져오기에서 XLSX·PDF는 아직 못 읽습니다 → 은행 앱이나 엑셀에서 CSV로 저장해서 가져오세요.
- 자동 백업은 "정해진 주기마다 알려 주고 한 번에 공유"하는 방식입니다 (백그라운드에서 폴더에 자동 저장하지는 않음).
- 음성 기록은 앱 안의 마이크 버튼 대신 휴대폰 키보드의 음성 입력을 씁니다.

## 실행

```bash
cd haru-money
npm install
npx expo start          # Expo Go(SDK 58)로 열기
npm test                # 엔진 테스트 (문장 해석, 카드·할부, 예측, 빚, 가져오기, 암호 백업)
```

모든 기능이 Expo Go에서 동작합니다. APK: `npx eas-cli@latest build -p android --profile preview`

## 구조

```
src/domain/   안드로이드와 무관한 규칙 (테스트 대상)
  phrase.ts     문장 해석            money.ts    금액 해석·표시
  ledger.ts     잔액·카드 청구서·할부  engine.ts   예측·고정 항목·전망·이상 지출·건강 점수·XIRR·흐름
  debts.ts      빚 일정·숨은 이자·상환 계획   importer.ts  CSV/OFX 읽기와 확인 후보
  backup.ts     JSON/암호 백업·CSV    normalize.ts 불러온 데이터 검사   sample.ts 예시 데이터
src/store.tsx  저장(AsyncStorage)·알림
src/screens/   홈·내역·계획·분석·설정·가져오기·사용법
test/          node:test 테스트 (npm test)
```
